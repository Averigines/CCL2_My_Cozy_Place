# This project is currently not usable locally because the database is inaccessible.

## Description
Concept of a C2C marketplace coded as a solo-project at the end of my second term in my bachelor studies 'Creative Computing'. 

## Features
- User registration and login
- Item management (add, view, delete)
- Image upload
- User profile management

## Tech Stack
- Node.js
- Express.js

## Setup

### Prerequisites
- Node.js (v14 or higher)
- npm 
  ```sh
  npm install -g npm
  ```

### Steps
1. Clone the repository:
    ```sh
    git clone https://github.com/Averigines/CCL2_My_Cozy_Place.git
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

3. Run the application:
    ```sh
    node app.js
    ```

4. Open your browser and navigate to `http://localhost:5000`.
